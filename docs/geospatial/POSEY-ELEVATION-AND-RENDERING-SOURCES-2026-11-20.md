## Building-height pipeline

The [Building 3D Tiles workflow](../../.github/workflows/building-3d-tiles.yml) uses the projected bounding box of each footprint part plus a 50 ft ground-search buffer to identify required source tiles. The single-tile pass processes only windows fully contained in one nominal grid cell. When a search window crosses an edge or corner, recovery combines the required COPC tiles and counts returns once using half-open grid bounds. A missing or invalid source leaves the height unavailable. The source inventory covers both processing paths.

Both passes check the LAS horizontal CRS (EPSG:2968), vertical CRS (EPSG:6360) and the relationship between LAS header bounds and the named tile. NOAA's delivery record supplies GEOID12B lineage. The software keeps the 23,082-height acceptance requirement and retains explicit gap evidence. COPC checkpoints from earlier extraction code require a fresh run because checkpoint identity includes the script hash.
