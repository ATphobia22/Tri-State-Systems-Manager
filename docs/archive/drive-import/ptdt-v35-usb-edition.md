System Overview
The PTDT V35 USB edition is an offline, air-gapped sovereign node deployment of the Tri-State Systems Manager (TSM). It is designed to run the Archimedes Core solver API, a containerized PostGIS database, and a WebGPU/React viewport entirely from a portable 32GB NAND Flash drive.
All systems are cryptographically sealed to enforce non-mutation rules and satisfy Daubert evidentiary standards (FRE 702), ensuring the validity of geodetic invariants at the anchor site:
