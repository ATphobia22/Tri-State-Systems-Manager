# 13_grants — 47620 funding pathways

- `47620-grant-master-matrix-v1.json` — structured catalog from the Grant Master Matrix PDF (planning only).
- Source PDF: project attachments / user-supplied `47620_Grant_link Matrix .pdf`.

**Rules**

1. Verify every program on the official portal (NOFO, match, deadline, eligible applicants).
2. Organizational applicants need SAM.gov UEI where required.
3. USACE Section 205 needs a **public sponsor** — not an individual self-sponsor.
4. This folder is not a grant application and does not imply award or eligibility.
