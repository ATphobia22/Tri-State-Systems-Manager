## Notes from the documents

- **OCRA:** "no exceptions" on proposal/application deadlines; technical support
  unavailable after 3 p.m. ET the Friday before each deadline. The proposal must
  be ≥95% complete documentation. A Community Liaison site visit happens between
  proposal and application (at OCRA's discretion).
- **IDEM 319:** applications are only reviewed from applicants with an **approved
  NOI**. The FFY2027 cycle is closed; the next solicitation would be a new
  document — watch IDEM's NPS grants page.
- **USDA:** "Applications are accepted year round using RD Apply." Start with the
  local Rural Development state office.
- **USACE 205:** starts with a Letter of Intent; the Corps then does a Federal
  Interest Determination at federal expense when funding is available.
- **USACE PAS:** contact the local District's Planning Department; template
  agreements on the Corps HQ website.
