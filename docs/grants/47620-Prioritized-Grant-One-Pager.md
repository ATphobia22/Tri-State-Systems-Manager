## 1. FEMA BRIC — scoring snapshot (National Competition)

FY 2024–2025 style national competition uses a **100-point** evaluation model (criteria evolve with each NOFO — **re-read the current NOFO**).

| Criterion | Max pts (illustrative) | What scores |
|-----------|------------------------|-------------|
| Infrastructure project **construction readiness** | **30** | Conceptual (~30% design) ≈ 5; preliminary (>30%) ≈ 15; detailed (**≥90%**) ≈ 30 |
| New applicant / subapplicant (never selected in BRIC national competition) | **15** | First-time selection bonus |
| Building code adoption & enforcement | **20** | Modern IBC/IRC adoption + strong BCEGS-type enforcement |
| Small impoverished community | **5** | Statutory definition; can also affect cost-share |
| Risk reduction narrative | **20** | Clear hazard, quantified risk reduction, resilience, ancillary benefits |
| Implementation measures | **10** | Cost/schedule management, capacity, monitoring |

**Hard constraints typically include:** eligible subapplicant (state/local/tribal or certain nonprofits as allowed); cost-effectiveness (**FEMA BCA**); alignment with approved hazard mitigation plan; **phased projects often ineligible** under recent rules; non-federal cost share (reduced share possible for small impoverished communities).

**47620 implication:** BRIC is a **strong long-term** path only after a **public subapplicant** has a defined infrastructure project and real design progress. TSM evidence packages support the narrative; they do not replace design/BCA.

## 2. Indiana OCRA CDBG — Stormwater Improvements Program (SIP)

| Item | Typical published parameters |
|------|------------------------------|
| **Administrator** | Indiana Office of Community and Rural Affairs (OCRA) |
| **Applicant** | Non-entitlement city, county, or incorporated town (lead applicant) |
| **Max award (SIP)** | **$750,000** (not a target; OCRA may scale) |
| **Match** | **10%** of total project cost (confirm current round instructions) |
| **Beneficiary cost guide** | Often referenced around **$5,000** CDBG per project beneficiary |
| **National objective** | Typically **LMI area benefit** for SIP |
| **Eligible work examples** | Retention, storm lines, drainage rehabilitation, flood-reduction stormwater improvements; green infrastructure often scored |
| **Process** | Proposal → pre-approval → full application via **eGMS**; multiple rounds per year |

**Always use the current round instruction PDF** on in.gov/ocra.

**47620 implication:** Best **near-term construction-scale** fit if Mount Vernon or Posey County can show LMI benefit, stormwater utility/user-rate story where scored, and local match. Private LOMA work is separate from SIP.

## 3. Recommended 90-day action sequence

1. **County / City decision** — Who is the lead applicant (Mount Vernon vs Posey County) for stormwater vs Section 205?  
2. **OCRA liaison call** — Confirm next SIP round dates, LMI survey needs, open grant limits.  
3. **Project definition one-pager** — Location, problem (flooding/drainage), beneficiaries, cost band, match source.  
4. **Section 205 LOI draft** — Only if Commissioners willing to sponsor; attach problem statement.  
5. **BRIC** — Park until design ≥30% and state coordination is real; use TSM for risk narrative only.  
6. **LOMA 26-05-2022A** — Continue in parallel (property-level map path; not a grant).
