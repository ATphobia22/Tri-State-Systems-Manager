## Suggested sequence (next 30–60 days)

1. **Week 1–2:** Finish LOMA evidence (adjacent LAS or DEM clip, SHA-256, PDAL Class 2 note, FARA PDF, FIRMette).  
2. **Week 2:** Send Community Acknowledgment request to floodplain administrator (verify name/address).  
3. **Week 2–3:** File IDNR Site Review / BFE reconciliation if FARA shows 368.7 vs Map Pack 375.0.  
4. **Week 3–4:** Upload complete Map Pack under **26-05-2022A**.  
5. **Before 1 Sep:** If pursuing §319, lock sponsor + scope + match letters.  
6. **1–30 Sep:** CCMG only if AMP approved and project is road/drainage-eligible.  
7. **Parallel:** Track OCRA NOFA and next BRIC cycle; do not force-fit residential Pure LOMA into BRIC.
