# FEMA BRIC eligibility (explore)

## Who can apply

| Role | Eligible entities (typical) |
|------|-----------------------------|
| **Applicant** | States, DC, U.S. territories, federally recognized Tribal Nations (usually **one** application per applicant) |
| **Subapplicant** | Local governments, communities, special districts, Tribes applying **through** the state/territory |

Posey County / Point Township work is normally a **subapplication through the State of Indiana**, not a direct federal application by a private landowner.

## What BRIC funds (conceptually)

Capability- and project-building for **hazard mitigation** before disaster: infrastructure, flood-risk reduction, building codes, planning capacity — exact eligible activity lists are in the **current NOFO**.

## What BRIC is not

- Not a LOMA / map amendment process  
- Not a substitute for case **26-05-2022A**  
- Not automatic funding for a single residential Pure LOMA packet  

## Cost share

Many HMA activities historically use ~**75% federal / 25% non-federal**. **Confirm in the live NOFO.** State programs (e.g. OCRA CDBG) are sometimes used to help local match — coordinate to avoid ineligible stacking.

## FY2024–25 cycle (public figures — verify live)

- Combined opportunity on order of **$1 billion** after 2025 program disruption  
- Application window cited open ~**25 Mar 2026**, close **23 Jul 2026, 3 p.m. ET**  
- Apply via **FEMA GO**

If you are reading after that close date, treat the cycle as closed and monitor the next NOFO only.

## Indiana practical path

1. Confirm project is in / consistent with the **approved hazard mitigation plan**.  
2. Contact state HMA / SHMO channel early.  
3. Use TSM only for **evidence and scoping**, not for submission.  

**Human authority remains final.**
