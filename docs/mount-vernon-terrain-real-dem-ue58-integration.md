## Production Python Transvoxel verification

```sh
export TSM_DEM_VERTICAL_UNIT=us-ft  # NOT source-verified; explicit preview only
python scripts/geospatial/mount_vernon_multi_dem_camera_sweep.py \
  --raster IN2020_26700930_12.tiff \
  --sha256 1a321bc386e0de8b7cca74ec903fb35ea8fb54e8cdd7e835428210562e173ebb \
  --grid 4 --output results/dem-A-sweep.json --preview-only

python scripts/geospatial/mount_vernon_multi_dem_camera_sweep.py \
  --raster IN2020_26850945_12.tiff \
  --sha256 78f987ad4f93d3680d4500ad0b74542872f83529861b5500863addb61c00d124 \
  --grid 4 --output results/dem-B-sweep.json --preview-only
```

This invokes the **existing production `mesh_transition_cell` code** over 16 distinct DEM windows per file, comparing actual mesh/plane triangle intersections for each adjacent transition-cell pair. It does not generate an adaptive octree or test mixed-LOD final chunk topology; label that gate `NOT_EVIDENCED` until it is built and independently validated. Tests produce raw sample geometry and timings, not GPU screenshots.

## Map layers and Unreal placement

Unpack the Google Drive preview. The bundle has `tileset.json`, `dem-footprints.geojson`, two raster hillshade PNGs, 32 GLB files, `manifest.json`, and `unreal-placements.json`. These are usable visualization layers but MUST display `PENDING_EVIDENCE` for all unverified elevation-related attributes. Native UE5.8:

1. Enable Python Editor Script Plugin and glTF Interchange import in Unreal Editor.
2. Open an existing saved World Partition level; no `.umap` file is claimed/generated by this repository change.
3. Set `TSM_MV_TILES_DIR` to the unpacked preview assets folder.
4. In UE Editor Python console, run: `exec(open(r"tsm-native/Tools/Import-MountVernonPreviewTerrain.py").read())`.
5. Save the level, inspect terrain positions and seams, run the existing `tsm-native/Tools/Prepare-WorldPartition.ps1` HLOD build, and run the established Windows BuildCookRun pipeline.
6. Headed-test the packaged Windows 11 Shipping executable **offline**, record screenshots, FPS, frame times and GPU/VRAM, verify no localhost/WebView/Node dependency.

## Exit criteria for actual release

- Complete contiguous DEM AOI acquired, source date/QL and vertical datum/units independently confirmed.
- Real SDF adaptive octree with 2:1 leaf balancing and official table-driven Transvoxel transition meshes emitted for **all mixed-LOD faces**.
- 0 unbalanced neighbor face pairs and 0 unexplained shared-face mismatches or overlapping triangles, measured with source-aware tolerances.
- Deterministic physical camera-pan screenshots + telemetry prove LOD changes without visual cracks.
- UE5.8 saved World Partition `.umap`, HLOD artifacts, packaged Win64 Shipping executable and offline headed acceptance receipts stored and hash-linked.
- Source and derived data evidence receipts ingested into TSM evidence ledger, distinct from the public preview manifest.
