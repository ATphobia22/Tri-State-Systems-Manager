# docs/loma — reference material

## hawaii-dlnr-annotated-firmette-guide-2015.pdf

**Source:** State of Hawaii, Department of Land and Natural Resources,
Engineering Division — *A Step-by-Step Guide for Creating Annotated Effective
and Historic FIRMettes*, January 2015 (www.hawaiinfip.org). 17 pages.
SHA-256: `bf6868b2bdf243d2…`

**What it is:** A genuine state-published procedure guide for annotating
FEMA FIRMettes. Kept as **procedure reference only** — it is a Hawaii DLNR
publication, not a FEMA publication, and carries no regulatory authority.
Useful context for FIRMette annotation workflow; never cite as authority
for a LOMA determination. FEMA determinations come from the FEMA letter /
Online LOMC process.
