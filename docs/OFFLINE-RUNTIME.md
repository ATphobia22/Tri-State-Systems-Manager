# TSM Offline Runtime

The offline runtime is integrated into the TSM repository as a materialized runtime plane, while its large dependency cache remains an external, checksum-locked artifact rather than Git-tracked source.

## Install the downloaded runtime

From the repository root on Windows:

    ./scripts/offline/install-bundle.ps1 -Bundle ./TSM-OFFLINE-RUNTIME-76a0655656a422ad66b6b71d79ef063ee8b6068a.zip

Then verify:

    node ./scripts/offline/verify-installed-runtime.mjs

The installer verifies the outer bundle SHA-256 before extraction.

## Integrated runtime planes

- Doctor and layout validation
- Offline npm dependency cache
- Vite production build
- Existing Node API runtime
- /health verification
- TSM hydraulic contracts and read-only HDF5 reader
- Tauri/Rust dependency vendor tree
- Provenance and SHA-256 manifests
- Fail-closed authorized HEC-RAS adapter boundary

## Platform boundary

The locked artifact was generated by Linux CI. It is not silently treated as Windows-compatible. Python wheels, Rust/native artifacts, and any platform-specific binaries must match the target operating system and architecture before offline execution.

The HEC-RAS executable is intentionally not bundled. An authorized local HEC-RAS installation remains an external solver dependency.
