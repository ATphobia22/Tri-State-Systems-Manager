**Program:** Building Resilient Infrastructure and Communities  
**Status (as of mid-2026 public sources):** Combined **FY2024–FY2025** NOFO issued after earlier 2025 program turbulence; **$1 billion** total opportunity.

## Structure (high level)

- **Applicants:** States, DC, territories, federally recognized Tribes (one application per applicant)  
- **Subapplicants:** Local governments, communities, special districts (apply **through** the state)  
- Categories include state/territory allocation, tribal set-aside, building code plus-up (amounts per NOFO fact sheet)

## Indiana path for Posey resilience

1. Work **through Indiana** (state applicant / SHMO / appropriate HMA contact) — localities are typically **subapplicants**.  
2. Align projects with approved hazard mitigation plan.  
3. Cost share historically often ~**75% federal / 25% non-federal** for many HMA activities — **confirm in current NOFO**.  
4. Stack carefully with OCRA CDBG / other state match sources; no double-dipping.  
5. TSM Grant Intelligence may **track** NOFOs; it does **not** submit applications.
