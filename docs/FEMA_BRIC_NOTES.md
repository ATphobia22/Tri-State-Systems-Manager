# FEMA BRIC (Building Resilient Infrastructure and Communities) — Verified Notes

**Status (as of 2026):** FY2024–FY2025 combined NOFO published; application window opened 25 Mar 2026, closes **23 Jul 2026, 3 p.m. ET**. Apply via FEMA GO (`https://go.fema.gov`).

## Eligibility
- **Applicants:** States, DC, territories, federally recognized Tribal Nations (one application per applicant).
- **Subapplicants:** Local governments, communities, special districts, Tribes (through state/territory).
- Individuals / businesses / nonprofits cannot apply directly.

## Funding (FY24–25 combined ~$1B)
- State/Territory allocation, Tribal set-aside, Building Code Plus-Up, National Competition (up to $20M federal share per subapplication).
- Cost share required (typical 75% federal / 25% non-federal; higher federal share possible for economically disadvantaged rural communities).

## Eligible activities (examples)
- Hazard mitigation infrastructure and construction that reduce risk.
- Building code adoption/enforcement tied to resilience.
- Facility relocation / elevation / flood-risk reduction projects.

## Posey County pathway
1. Coordinate with Indiana state hazard mitigation officer / EMA.
2. Align project with local Hazard Mitigation Plan.
3. Document BCA (Benefit-Cost Analysis); PTDT site notes BCR 2.45 as internal planning figure only.
4. Submit subapplication through state into FEMA GO before deadline.
