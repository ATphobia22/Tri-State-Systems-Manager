**Status:** SCREENING TEMPLATE ONLY — not a regulatory determination, not a
permit application, not a substitute for DNR review. Mirrors the worksheet's
assessment structure so TSM pre-screening collects the same inputs DNR will ask
for.

## When this assessment approach applies (per the form)

Appropriate for most floodway projects, **except**: new and replacement-in-kind
bridge projects, projects located entirely within the shadow of a bridge, dam
construction projects, or reconstruction of a building. (Those use State Forms
55233, 55235, or full modeling instead.)

## Minimum plan details & computation requirements (mirror)

For each item, TSM screening records: included? (yes/no) and the sheet/page
reference — mirroring the form's Column 1 / Column 2 / Column 3 structure.

**Plan views required:**
1. Location map — project site in relationship to the waterway and surrounding
   roadways.
2. Aerial plan view — disturbed area of the project site.
3. Construction-components plan view — permanent and temporary components
   throughout the site.
4. Floodway plan view — floodway throughout the project limits.
5. Cross-section view(s) — overlay comparison of **pre-construction vs
   post-construction** effective cross-sectional flow area at the most
   restrictive segment(s) of the encroachment. Cross sections stationed
   **left to right, looking downstream, full valley, oriented perpendicular
   to flow**.
6. Methodology description — "identify the software or show computations"
   used for cross-sectional area.
7. Cross-section location plan — clearly marked location(s) and labels.
8. Photos (4, orientation labeled):
   - from the project site, downstream view of the channel;
   - from the project site, upstream view of the channel;
   - from a downstream streambank, view of the project site;
   - from an upstream streambank, view of the project site.

**Plan standards (per the form):** horizontal and vertical scale, vertical
datum, north arrow, labels, stations, and date on all plans.

**Companion documents (per the form):**
- Completed "Change in Effective Cross Sectional Flow Area Worksheet,
  Companion Worksheet A" (State Form 57166).
- Completed "Fish, Wildlife, and Botanical Resources Impact Assessment
  Worksheet" (State Form 57132).

**Signature block:** printed name of preparer, signature, date signed
(mm/dd/yyyy).

## TSM screening pass/fail posture

- The form's own notice: "after reviewing the submitted plans and computations
  … IDNR staff may request additional documentation if sufficient evidence has
  not been provided that clearly demonstrates the effect that the project may
  have on the base flood elevation."
- TSM mirrors that posture: any missing plan detail → screening result
  `NOT_EVALUATED`, never an inferred pass. A TSM "screen" is not DNR's
  determination.
- Related worksheets on file: 55233 (bridge assessment), 55235 (development in
  the shadow), 57132 (fish/wildlife/botanical). The 55235 worksheet additionally
  defines BFE sources DNR accepts: published FIS/flood study, LOMR (case #),
  approved DNR-permit model (permit #), DNR FARA (INFIP/DNR FARA #) — with BFE
  value **and datum** recorded.
