## DEM: visualize != measure

[IndianaMap's DEM dataset](https://www.indianamap.org/datasets/indiana-2016-2020-dem/about) describes a hydro-flattened bare-earth QL2 LiDAR DTM; the original 2.5-foot pixel program is separate from any output resampling. The official [ImageServer](https://di-ingov.img.arcgis.com/arcgis/rest/services/DynamicWebMercator/Indiana_2016_2020_DEM/ImageServer) exposes EPSG:3857 horizontal extent, one-band F32, `GrayscaleHillshade`, `Indiana Shaded Relief`, slope and aspect rendering functions, and `LatestVCSWkid(0)`. **No vertical datum may be inferred from that service CRS declaration.** A displayed ~0.305-meter pixel size is **not proof** that the native source raster's original spacing is 0.305 m or that its Z values are meters.

Recommended **authoritative tile discovery**: [Indiana DEM Tile Footprints 2016–2020 (FeatureServer layer 0)](https://gisdata.in.gov/server/rest/services/Hosted/Indiana_DEM_Tile_Footprints/FeatureServer/0) followed by the IGIO-managed [Indiana elevation AWS S3 source](https://registry.opendata.aws/in-elevation/) and its original per-tile metadata. Treat any predicted tiles generated from a 5,000-ft lattice as *candidates* until a publisher footprint and actual S3 object match. Existing Posey planning PR #581 must keep actual 23,082 building OBJECTIDs and never certify missing 2,566 roof heights based on a bare-earth DTM.

The repository's DEM export script now separately inspects each **actual** local TIFF's signature, Float32 one-band form, EPSG:3857, requested bounds, dimensions, and at least one valid finite pixel. It rechecks resumed files instead of accepting an arbitrary nonzero byte count. Successful structural checks **do not** certify original source resolution, vertical reference/units, accuracy, water level, NFIP acceptability or roof geometry.

## Riverine model gate and QA matrix

| Component | Inputs/evidence required before claimed result | Failure disposition |
|---|---|---|
| DEM ground sample | Source tile and digest, native CRS, horizontal transform, producer NAVD88/geoid/units metadata, actual valid pixels | Null ground Z + `UNAVAILABLE`, keep 2D footprint |
| Building extrusion | Authoritative footprint OBJECTID, actual roof and ground samples, vegetation screening, provenance/confidence, consistent Z frames | No synthetic height or default verified 3D roof |
| Flood study surface | Effective FIS/FIRM and model metadata, current FEMA standards, scenario designation, accepted solver/version, QA reports | Informational-only output; no signed FEMA determination |
| cHECk-RAS-inspired diagnostic | Explicit steady/unsteady classification, roughness and transition losses, structures, cross sections, floodway and profiles | Never call historic cHECk-RAS for unsteady/2D or treat its warning-free report as certified |
| Ecological action screening | Actual project area, activity, species occurrence/current agency record, consultation and mitigation evidence | Mark environmental status NOT EVIDENCED; do not borrow Upper Mississippi opinion |
| Public accountability | Published input sources and timestamps, impact/uncertainty warnings, data-quality metrics and human review state | No agency certification or community-endorsement claim |

**Regulatory boundary:** outputs are engineering research/informational support only until appropriate human/agency approval. The source documents cannot independently prove a certified Posey building-height dataset, complete DEM staging, HEC-RAS 6.x accepted design or Windows UE5.8 Shipping build.
