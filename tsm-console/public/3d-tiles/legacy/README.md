# Legacy 3D Tiles Archive

## buildings-glb-legacy/
4,121 individual building GLB files from a legacy (pre-2026-10) processing pipeline.

**Status:** ARCHIVED - NOT PRODUCTION DATA

- These GLBs use OBJECTIDs from an older dataset that does not match the current
  authoritative 22,815-building source (only 25 of 4,121 IDs overlap).
- They are NOT referenced by the production MapLibre application.
- They are NOT subject to production validation gates.
- Preserved for historical reference only, per owner direction to retain all layers.

**Production building data:** `../buildings-3d.json` (22,815 features, validated)
**Production 3D Tiles:** `../buildings-lidar-12450/` (implicit tiling, validated)
**Production terrain:** `../terrain-3dep/` (validated)
