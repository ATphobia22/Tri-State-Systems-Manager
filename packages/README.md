# TSM packages

Workspace packages for Tri-State Systems Manager:

- `@tsm/agent-runtime` — ADR-006 autonomy ladder
- `@tsm/approvals` — human decision records
- `@tsm/browser` — capability detection
- `@tsm/search` — catalog / gage search model
- `@tsm/jobs` — job kinds
- `@tsm/queues` — Memory default + optional BullMQ
- `@tsm/notifications` — informational sinks

See `docs/adoption/HYDRO-GEOSPATIAL-OSS-STACK-2026-10-23.md`.
