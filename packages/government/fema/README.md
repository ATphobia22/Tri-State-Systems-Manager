# FEMA adapter

Authority: FEMA NFHL MapServer and FEMA Map Service Center. The existing canonical NFHL layer registry and live validator remain the source of layer inventory expectations. This package boundary covers NFHL, FIRM, LOMA, LOMR, and Risk MAP discovery; it does not issue regulatory determinations. Query results must retain effective dates, layer IDs, panel/community identifiers, request URL, retrieval timestamp, and SHA-256. See `packages/geo/src/nfhl/` and run `npm run nfhl:validate`.
